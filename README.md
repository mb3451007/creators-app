# 🔷 OBO – Social Media Platform with Live Streaming (Frontend)

OBO is a scalable social media platform built with Angular, featuring real-time chat, post creation, live streaming, and a premium content system. The frontend handles all user interactions, social features, and admin dashboard functionality.

## 🚀 Features

- User registration/login with Google/Facebook OAuth
- Real-time chat with friend requests and notifications
- Full social features: posts, likes, comments, user profiles
- Live streaming and premium content access
- Admin dashboard to manage posts, users, and content
- Responsive layout with modern UI components

## 🌐 Tech Stack

- Angular
- Bootstrap / Tailwind CSS (optional)
- ngx-translate / i18n
- Angular Material
